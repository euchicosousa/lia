# Registro de rotas

Este app não usa rotas curtas: os botões apontam direto para o WhatsApp de cada clínica.

| Rota | Destino                                | Onde fica | Rastreada |
| ---- | -------------------------------------- | --------- | --------- |
| `/`  | Página principal (`public/index.html`) | arquivo   | sim*      |

\* Registra visita e cliques (`data-track`) quando os IDs forem preenchidos em `public/tracking.js`.
